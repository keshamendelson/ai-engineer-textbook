# AI-инженер с нуля

Интерактивный учебник по AI-инженерии на русском языке: от векторов и градиентного
спуска до RAG, речи, зрения, генеративных моделей и инженерии инференса.

Автор русскоязычной адаптации: **Евгений Миронов**. Права на исходные учебники
и курсы остаются за их авторами, полный список ниже и в приложении C.

Открывается в браузере без установки и без интернета.

```bash
cd site && python3 -m http.server 8899
# затем http://localhost:8899
```

## Что внутри

| | |
|---|---|
| Глав | 33 плюс 4 приложения, около 105 тысяч слов прозы |
| Схем и иллюстраций | 110 инлайновых SVG, работают в светлой и тёмной теме |
| Интерактивных демо | 14: от косинусной близости и градиентного спуска до разметки BIO, спектрограммы, выравнивания CTC, свёртки, шагов диффузии, бюджета задержки и маршрутизации экспертов |
| Вопросов с разбором | 187 |
| Терминов в глоссарии | 218, подсказка при наведении и ссылка на статью глоссария прямо из текста |
| Времени | около 16 часов чтения, около 64 часов вместе с задачами |

Все цифры выше считает `tools/estimate_time.py` по факту, руками они не проставляются.

Прогресс чтения сохраняется в браузере. Тёмная тема, мобильная вёрстка и печать поддерживаются.

## Как это собрано

Разделение труда: структура, схемы, таблицы, код и ключи к квизам заданы в спеках
вручную, прозу пишет модель `gpt-5.6-luna` через шлюз Lenec. Вызовы идут параллельно,
один поток на блок текста.

```bash
# собрать главу заново
python3 tools/write_chapter.py specs/ch13.json --workers 12

# литературная правка уже готовых глав
python3 tools/polish.py site/ch13.html --dry-run

# проверка перед сдачей
python3 tools/lint.py site/*.html --fail

# пересобрать поиск и глоссарий после правок
python3 tools/glossary_data.py && python3 tools/mark_terms.py && python3 tools/build_index.py
```

Ключ и адрес шлюза берутся из `OPUS_API_KEY` и `OPUS_BASE_URL`, либо из
`~/projects/claude-tg-bot/.env`. В этот репозиторий секреты не копируются.

### Что проверяет линтер

Длинное тире, антитезы «не X, а Y», канцелярит, раздутую значимость, заголовки по
шаблону «термин: пояснение», пустые блоки после сбоя генерации и иностранные слова
посреди русской фразы. Последнее ловит реальный класс дефектов: модель несколько раз
подставляла в текст английские и немецкие слова и один раз переписала имя модели
`Qwen2.5-0.5B-Instruct` на собственное.

## Вопросы к первоисточникам

Обе базовые книги нарезаны в поисковый корпус. Можно спросить и получить ответ
со ссылками на разделы оригинала.

```bash
python3 rag/build_corpus.py                 # один раз
python3 rag/openai_store.py upload          # создать хранилище
python3 rag/openai_store.py ask "что такое induction head"
```
