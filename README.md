# AI-инженер с нуля

Интерактивный учебник по AI-инженерии на русском языке: от векторов и градиентного
спуска до RAG, речи, зрения, генеративных моделей и инженерии инференса.

Автор русскоязычной адаптации: **Евгений Миронов**. Права на исходные учебники
и курсы остаются за их авторами, полный список ниже и в приложении C.

Открывается в браузере без установки и без интернета.

```bash
cd site && python3 -m http.server 8899
# затем http://localhost:8899
```

## Что внутри

| | |
|---|---|
| Глав | 59 плюс 4 приложения, около 282 тысяч слов прозы |
| Схем и иллюстраций | 196 инлайновых SVG, работают в светлой и тёмной теме |
| Лабораторий с кодом | 7 в главах 2 и 13: обучение с нуля и поиск по своим документам, весь код запускался на обычном ноутбуке |
| Интерактивных демо | 20: от косинусной близости и градиентного спуска до разметки BIO, спектрограммы, выравнивания CTC, свёртки, шагов диффузии, бюджета задержки и маршрутизации экспертов |
| Вопросов с разбором | 345 |
| Терминов в глоссарии | 296, подсказка при наведении и ссылка на статью глоссария прямо из текста |
| Времени | около 39 часов чтения, около 121 часа вместе с задачами |

Все цифры выше считает `tools/estimate_time.py` по факту, руками они не проставляются.

Прогресс чтения сохраняется в браузере. Тёмная тема, мобильная вёрстка и печать поддерживаются.

## Структура репозитория

```
site/                готовый учебник, открывается как есть
  index.html         главная с оглавлением и картой
  ch00…ch56.html     главы, математика части I разбита на 1.1-1.4
  app-a…app-d.html   глоссарий, шпаргалки, библиотека ресурсов, питон с нуля
  assets/            стили, движок, оглавление, глоссарий, поисковый индекс

specs/               спеки глав: структура, схемы, таблицы, код, ключи к квизам
tools/               конвейер сборки
  write_chapter.py   собирает главу: проза от gpt-5.6-luna, схемы из спеки
  check_spec.py      валидатор спеки до сборки: структура, SVG, стиль, объём
  polish.py          литературная правка готовых глав той же моделью
  lint.py            проверка на AI-паттерны, порчу фактов и обрывы генерации
  mark_examples.py   курсив для английских примеров, чтобы линтер их не путал с порчей
  enrich.py          точечные вставки в готовые главы: выводы формул, источники, задания
  estimate_time.py   честный пересчёт времени чтения и практики
  source_extract.py  выдержка из корпуса книг под конкретную главу
  check_links.py     проверка всех ссылок
  check_svg.js       наложение подписей и выход за холст в схемах, запускается в консоли браузера
  add_demo.py        вставка готового демо в собранную главу
  build_toc.py       добавление новых глав в оглавление
  glossary_data.py   глоссарий как данные, собирает app-a.html и подсказки
  mark_terms.py      подчёркивает термины в тексте для подсказок
  build_index.py     поисковый индекс
  make_specs*.py     генераторы спек

rag/                 корпус первоисточников для вопросов к книгам
  build_corpus.py    PDF → чанки (516 фрагментов, 540 тыс. слов)
  openai_store.py    загрузка в OpenAI vector store и запросы
  corpus/            собранный корпус

sources/             исходные PDF (UDL, SLP3)
```


## Источники

- [Understanding Deep Learning](https://udlbook.github.io/udlbook/), Simon J.D. Prince
- [Speech and Language Processing](https://web.stanford.edu/~jurafsky/slp3/), Jurafsky & Martin
- [LLMs from scratch](https://github.com/rasbt/LLMs-from-scratch), Sebastian Raschka
- [Hands-On Large Language Models](https://github.com/HandsOnLLM/Hands-On-Large-Language-Models), Alammar & Grootendorst
- [Designing ML Systems](https://github.com/chiphuyen/dmls-book), Chip Huyen

Части XIV, XV и XVI (главы 50-56) выросли из курируемого списка
[awesome-artificial-intelligence](https://github.com/owainlewis/awesome-artificial-intelligence),
Owain Lewis. Оттуда взяты спецификации протоколов, инженерные разборы Anthropic,
OpenAI и Google, обзор агентных фреймворков и кодинг-агентов, десять статей
и подборка курсов. Каждый ресурс подписан автором и снабжён ссылкой прямо
в тексте той главы, где о нём идёт речь.

Полный список с пометками, кому что подходит, в [приложении C](site/app-c.html).
