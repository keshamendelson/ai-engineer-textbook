# Лаборатории учебника

Код, который читатель запускает у себя. Всё проверено на macOS с процессором
Apple M1 Pro и на Python 3.12. Тяжёлого железа не нужно: видеокарта не
используется нигде.

## Разовая настройка, десять минут

```bash
# 1. менеджер окружений, если его ещё нет
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. отдельное окружение для учебника
cd labs
uv venv --python 3.12 .venv

# 3. библиотеки
VIRTUAL_ENV=$PWD/.venv uv pip install -r requirements.txt
```

Дальше в каждой лаборатории команды запускаются так:

```bash
./.venv/bin/python ch02/01_loss.py
```

## Ключ к языковой модели

Нужен только там, где глава просит ответ модели. Подходит любой шлюз с
интерфейсом OpenAI: официальный, OpenRouter, корпоративный. Две переменные
окружения:

```bash
export LLM_BASE_URL=https://адрес-вашего-шлюза     # адрес шлюза
export LLM_API_KEY=ваш-ключ                        # ключ от шлюза
export LLM_MODEL=имя-модели-у-вашего-шлюза         # смотрите список у поставщика
```

Строчки удобно положить в конец файла `~/.zshrc`, тогда они будут подставляться
сами при открытии терминала.

## Что где лежит

| папка | глава | что собираем |
|---|---|---|
| `ch02/` | 2. Что значит «модель учится» | обучение с нуля на 60 квартирах: функция потерь, градиентный спуск, переобучение |
| `ch13/` | 13. RAG целиком | поиск по своим документам с ответом и ссылками на источник |

## Векторы считаются локально

Библиотека `fastembed` скачивает модель `paraphrase-multilingual-MiniLM-L12-v2`
один раз, это 220 мегабайт. Скачивание занимает от одной до восьми минут в
зависимости от канала. Дальше всё работает без интернета: 60 коротких абзацев
превращаются в векторы примерно за одну секунду.
