# Прокси для помощника по главе

Учебник лежит на GitHub Pages, то есть сервера у него нет. Помощнику сервер
всё-таки нужен по двум причинам: у шлюза Gonka нет CORS, а ключ, положенный
в исходники страницы, через день будет крутить чужие запросы.

Поэтому здесь один маленький Worker. Он принимает `POST` с фрагментом главы и
вопросом, ходит в модель и отдаёт ответ потоком.

## Порядок попыток

1. Шлюзы Gonka по очереди, у каждого свой ключ и свой идентификатор модели.
   Рабочая лошадка — `deepseek-ai/DeepSeek-V4-Flash-0731`: первый токен
   приходит примерно через полторы секунды, ответ целиком за пять.
2. Если не ответил ни один — бесплатный тариф Gemini как страховка.
3. Если и он молчит — читатель видит «Ни один шлюз сейчас не отвечает».

Переключаемся только пока не пошёл текст. Если поток начался и оборвался,
начинать заново нельзя: читатель увидит ответ дважды.

## Развернуть

```bash
cd worker
npx wrangler login
npx wrangler secret put GONKA_API_KEY      # ключ Gonka
npx wrangler secret put GONKA_GATEWAYS     # необязательно, см. ниже
npx wrangler secret put GEMINI_API_KEY     # необязательно, страховка
npx wrangler deploy
```

`wrangler deploy` напечатает адрес вида `https://aieng-ask.ИМЯ.workers.dev`.
Его нужно вписать одной строкой в `site/assets/ask.js`:

```js
var DEFAULT_ENDPOINT = "https://aieng-ask.ИМЯ.workers.dev";
```

Пока там пусто, помощник на сайте не появляется вовсе. Это сделано нарочно:
отсутствие кнопки лучше кнопки, которая ничего не делает.

## Несколько шлюзов и ротация ключей

`GONKA_GATEWAYS` — список в JSON, пробуется по порядку:

```json
[
  {"label":"joingonka","baseUrl":"https://gate.joingonka.ai/v1",
   "model":"deepseek-ai/DeepSeek-V4-Flash-0731","key":"jg-…"},
  {"label":"gonkagate","baseUrl":"https://api.gonkagate.com/v1",
   "model":"deepseek-ai/deepseek-v4-flash-0731","key":"gp-…"}
]
```

Регистр в идентификаторе модели у шлюзов разный, поэтому модель задаётся
отдельно для каждого. Если переменная не задана, берутся умолчания из кода и
единый `GONKA_API_KEY`.

Каталог Gonka меняется. Посмотреть живой список:

```bash
curl -s -H "Authorization: Bearer $КЛЮЧ" https://gate.joingonka.ai/v1/models
```

## Ключ Gemini

Бесплатный тариф в [Google AI Studio](https://aistudio.google.com/apikey),
модель по умолчанию `gemini-2.5-flash`, меняется переменной `GEMINI_MODEL`.
Тариф ограничивает число запросов, а не выставляет счёт: упрётесь — придёт
ошибка, а не списание.

## Ограничения

Стоят не ради денег: ответ обходится примерно в $0,000007, сто тысяч ответов
меньше доллара. Они нужны, чтобы прокси нельзя было использовать как
бесплатную болталку общего назначения.

| Что | Сколько |
|---|---|
| Вопрос | 600 знаков |
| Выделенный фрагмент | 3000 знаков |
| Фрагмент главы вокруг | 4000 знаков |
| Ответ | 700 токенов |
| Ожидание шлюза | 25 секунд |
| Запросов с адреса | 40 в минуту |

Плюс проверка заголовка `Origin`: запрос принимается только с сайта учебника.
Список адресов — переменная `ALLOWED_ORIGINS` в `wrangler.toml`, туда же
добавлен `localhost:8899` для работы на своей машине.

Лимит по адресу считает сам Cloudflare через привязку `ratelimit`, хранилище
для этого не нужно и в бесплатный тариф всё укладывается. Убрать привязку из
`wrangler.toml` — лимит просто исчезнет, остальное продолжит работать.

## Проверить на своей машине

```bash
cd worker
cp .dev.vars.example .dev.vars     # вписать ключи
npx wrangler dev --port 8787
```

Во второй вкладке терминала:

```bash
cd site && python3 -m http.server 8899
```

В консоли браузера один раз:

```js
localStorage.setItem("aieng.ask.endpoint", "http://127.0.0.1:8787/ask")
```

`.dev.vars` в `.gitignore` — ключи в репозиторий не попадают.
