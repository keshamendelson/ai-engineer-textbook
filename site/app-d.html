Как запустить код без установки

Все примеры кода в этой книге можно выполнить прямо в браузере, без установки чего-либо на компьютер. Бесплатный сервис Google называется Colab, работает в любом браузере и не требует ничего, кроме аккаунта Google. Откройте colab.research.google.com и войдите под своим аккаунтом.

После входа нажмите кнопку создания нового блокнота. На странице появится серый прямоугольник, это ячейка. В ячейку пишут код. Результат его выполнения появляется прямо под ней, без отдельного окна.

python
print("Привет, это моя первая ячейка")

Наберите эту строку в ячейке и нажмите сочетание клавиш Shift+Enter, либо кнопку в виде треугольника слева от ячейки. Под ячейкой появится результат: строка Привет, это моя первая ячейка без кавычек. Так устроена вся книга: код в ячейке сверху, результат его выполнения сразу под ней.

Ячеек в блокноте может быть много, и каждая выполняется только тогда, когда вы сами нажали в ней Shift+Enter. Если код в одной ячейке использует переменную, которая создаётся в другой, сначала выполните ту ячейку, где переменная появляется, а эту потом. Когда результат выглядит странно, надёжнее всего выполнить блокнот заново от начала: в меню среды выполнения есть пункт «Выполнить всё».

Блокнот сохраняется в ваш Google Диск автоматически. Вернуться к нему можно в любой момент с той же стартовой страницы Colab, там будет список последних открытых блокнотов.

Переменные, числа и строки

Переменная это имя, за которым закреплено значение. Присваивание выполняется знаком =, и после него имя слева указывает на то, что стоит справа.

python
model_name = "gpt-4.1-mini"
price_per_token = 0.00015   # условное число для примера
tokens_used = 1000

print(model_name)
print(tokens_used * price_per_token)

Число без точки, 1000, называется целым. Число с точкой, 0.00015, называется дробным. Текст в кавычках, "gpt-4.1-mini", называется строкой, и неважно, одинарные кавычки вы поставите или двойные, лишь бы одинаковые с обеих сторон. Имя переменной вы придумываете сами. Понятное имя вроде tokens_used стоит выбрать вместо короткого x: через месяц вы вспомните, что оно значит.

Списки и словари

Список это упорядоченный набор значений в квадратных скобках. Вектор [3.0, 4.0] из главы 1 это список из двух чисел. К элементу списка обращаются по номеру позиции, и нумерация начинается с нуля.

python
vector = [3.0, 4.0]
print(vector[0])    # 3.0, первый элемент, номер 0
print(vector[1])    # 4.0, второй элемент, номер 1
print(len(vector))  # 2, сколько всего элементов

Словарь хранит пары «ключ и значение» в фигурных скобках. В главе 1 есть пример: модель распределяет вероятность между словами, «дождь» 0.31, «снег» 0.12, «солнце» 0.08. Тем же словарём это записывается так.

python
probabilities = {"дождь": 0.31, "снег": 0.12, "солнце": 0.08}
print(probabilities["дождь"])   # 0.31, обращение по ключу

Разница со списком в способе доступа. У списка это номер места по порядку. У словаря это ключ, который вы сами придумали, например слово, как в примере выше.

Цикл for и условие if

Цикл for повторяет действие для каждого элемента списка или словаря. Тело цикла, то есть то, что повторяется, отмечается отступом в четыре пробела. Такой отступ обязателен, он показывает, где заканчивается тело цикла.

python
for word in probabilities:
    print(word, probabilities[word])

# дождь 0.31
# снег 0.12
# солнце 0.08
Грабли · отступы после копирования

Если скопировать код из PDF или из переписки, отступы иногда съезжают: где-то остаётся лишний пробел, где-то пробелы смешиваются с табуляцией. Python откажется выполнять такой код и укажет строку, где отступ не совпал с соседними строками. Самое надёжное лечение: выделить блок целиком, убрать отступы и расставить заново на глаз, ориентируясь на код рядом.

Условие if выполняет код только тогда, когда указанное выражение истинно. В главе 6 перплексия современных моделей на английской прозе лежит в диапазоне 8-15, и такую проверку легко записать одной строкой.

python
perplexity = 12.4

if perplexity < 20:
    print("модель уверенно предсказывает текст")
else:
    print("модель путается в тексте")

Отступ у if и else работает так же, как у цикла: строки внутри блока сдвинуты на четыре пробела, и по этому отступу Python понимает, какой код относится к какой ветке.

Функция

Функция это именованный кусок кода, который можно вызвать много раз с разными значениями. Определяют её словом def, значения на входе называются аргументами, а результат отдаёт слово return.

python
def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    len_a = sum(x ** 2 for x in a) ** 0.5
    len_b = sum(y ** 2 for y in b) ** 0.5
    return dot / (len_a * len_b)

print(cosine([3.0, 4.0], [1.0, 2.0]))   # около 0.984

Это та же формула косинусной близости из главы 1, записанная без NumPy: сумма произведений, делённая на произведение длин. В следующем разделе видно, чем такая версия хуже готовой библиотечной.

Библиотеки

Функция cosine выше работает, но на практике её никто не пишет заново в каждом проекте. Для типовых задач существуют библиотеки: чужой код, уже написанный, проверенный и подключаемый одной строкой.

Аналогия

Библиотека это готовый инструмент со склада. Нужен молоток, вы идёте на склад и берёте готовый экземпляр вместо того, чтобы ковать его самостоятельно. Библиотека даёт готовую функцию для операции, которую до вас уже реализовали много раз, и вам остаётся только вызвать её по имени.

Где аналогия ломается: молоток на складе служит десятилетиями без изменений. Библиотеку же время от времени обновляют, и код, который работал вчера, иногда перестаёт работать после обновления версии.

Чтобы воспользоваться библиотекой, её сначала устанавливают на компьютер, а затем подключают в коде словом import. Установка делается один раз командой pip install. Слово pip обозначает менеджер пакетов Python: программу, которая скачивает и ставит библиотеки по имени. В Colab большинство нужных библиотек уже установлены заранее, поэтому шаг установки часто можно пропустить и сразу писать import.

bash
pip install numpy
python
import numpy as np

a = [3.0, 4.0]              # обычный список
b = np.array([3.0, 4.0])    # массив NumPy с теми же числами

print(a + a)     # [3.0, 4.0, 3.0, 4.0], список удвоился по длине
print(b + b)     # [6. 8.], числа сложились поэлементно
print(b.shape)   # (2,), одномерный массив длиной 2

Часть после слова as задаёт короткое имя, под которым библиотека видна в коде дальше. Сокращение np общепринятое: его узнает любой, кто писал на Python, и в этой книге оно используется без исключений.

Список и массив выглядят похоже, но ведут себя по-разному. Список, сложенный сам с собой, склеивается в список вдвое длиннее исходного. Массив NumPy складывается поэлементно: каждое число прибавляется к числу на той же позиции, а длина результата остаётся прежней.

Атрибут .shape показывает форму массива: сколько в нём измерений и сколько чисел по каждому из них. У вектора из главы 1 форма это (2,), одно измерение из двух чисел. У матрицы 3 на 4 из той же главы форма это (3, 4): три строки и четыре столбца. Когда код в главах 3 и 4 падает с ошибкой про несовпадение форм, дело почти всегда в опечатке в форме одного из массивов, и первое, что стоит сделать, это напечатать .shape у каждого участника операции.

Как читать сообщение об ошибке

Ошибка на экране выглядит пугающе, особенно в первый раз: красный текст, незнакомые слова, стрелки. В ней почти всегда есть ответ на вопрос, что именно сломалось, нужно только знать, куда смотреть. Разберём три ошибки, с которыми вы точно встретитесь, если будете печатать код из этой книги руками.

NameError

Эта ошибка означает, что вы обратились к имени, которого Python не знает: опечатались в названии переменной или забыли создать её заранее.

python
probabilities = {"дождь": 0.31, "снег": 0.12, "солнце": 0.08}
print(probabilites["дождь"])
результат
Traceback (most recent call last):
  File "code.py", line 2, in <module>
    print(probabilites["дождь"])
          ^^^^^^^^^^^^
NameError: name 'probabilites' is not defined. Did you mean: 'probabilities'?

Читайте снизу вверх. Последняя строка называет тип ошибки, NameError, и после двоеточия объясняет её словами: имя probabilites не определено. Свежие версии Python часто подсказывают, что вы, скорее всего, имели в виду probabilities. Строкой выше символы ^^^ указывают ровно на то место в коде, где искать причину. Строка с номером, line 2, называет строку файла, где это произошло. В блокноте вместо имени файла будет номер ячейки, суть от этого не меняется.

IndexError

Эта ошибка означает, что вы попросили элемент списка по номеру, которого в списке нет.

python
vector = [3.0, 4.0]
print(vector[2])
результат
Traceback (most recent call last):
  File "code.py", line 2, in <module>
    print(vector[2])
          ~~~~~~^^^
IndexError: list index out of range

В списке vector два элемента, они лежат под номерами 0 и 1, потому что нумерация в Python начинается с нуля. Номера 2 в этом списке нет, отсюда и текст ошибки: индекс списка вне диапазона. Лечение простое: перед обращением к элементу по номеру проверьте длину списка через len(vector), если не уверены, что элемент там есть.

ModuleNotFoundError

Эта ошибка означает, что вы подключаете библиотеку, которая не установлена в текущем окружении.

python
import tiktoken
результат
Traceback (most recent call last):
  File "code.py", line 1, in <module>
    import tiktoken
ModuleNotFoundError: No module named 'tiktoken'

Здесь символов ^^^ нет, потому что ломается сама строка import, целиком. Лечится тоже одной командой: поставить библиотеку так, как показано в разделе про библиотеки, командой pip install tiktoken.

bash
!pip install tiktoken

Восклицательный знак в начале строки указывает Colab выполнить эту строку как команду терминала. После этого import tiktoken в следующей ячейке сработает без ошибки.

Ошибок в Python больше трёх, но у большинства то же устройство: тип ошибки в последней строке, объяснение после двоеточия, место в коде строкой выше. Если сообщение непонятно даже после разбора, скопируйте последнюю строку целиком в поисковик: обычно кто-то уже сталкивался с той же ошибкой и написал, что помогло.

Как работать с примерами из глав

В каждой главе в конце есть блок «Сделайте руками» с кодом, который можно скопировать целиком и выполнить. Со всеми примерами книги стоит работать одинаково, и это единственный навык, который правда нужен, чтобы учиться по этой книге без опыта в программировании.

  1. Скопируйте код целиком. Весь блок вместе с import в начале, одной операцией.
  2. Выполните как есть. Прежде чем что-то менять, убедитесь, что оригинал работает и выдаёт тот же результат, что написан в примере рядом с кодом.
  3. Поменяйте одно число. Ровно одно значение за раз.
  4. Посмотрите, что изменилось. Сравните новый результат со старым и постройте догадку, почему он изменился именно так.

Возьмём пример из главы 1. В блоке практики там есть такие строки.

python
a = np.array([3.0, 4.0])
b = np.array([1.0, 2.0])
print(a @ b)                      # скалярное произведение: 11.0

Выполните код как есть и убедитесь, что результат действительно 11.0. Затем поменяйте одно число, например второе значение в b, с 2.0 на -2.0, и снова нажмите Shift+Enter. Результат станет отрицательным. Вернитесь к тексту главы 1: там сказано, что отрицательное скалярное произведение означает противоположно направленные векторы, и сравните это со своим результатом на экране.

Так стоит поступать с любым кодом в книге. Часть строк вы поймёте не до конца: например, запись sum(x * y for x, y in zip(a, b)) из раздела про функции выше, это укороченная форма цикла, о которой это приложение не рассказывает подробно. Чтобы запустить пример и увидеть, что он делает, понимать каждую строку не обязательно. Достаточно понимать, что на входе и что получилось на выходе.
