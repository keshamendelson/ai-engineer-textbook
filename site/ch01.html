Глава идёт первой по счёту, и без нескольких терминов из мира AI обойтись не получится. Мы даём краткие предварительные определения в начале главы, чтобы вы не теряли нить повествования. Модель это программа, которая по входным числам считает выходные числа. Обучение это подбор чисел внутри модели ради получения лучших ответов, механика этого процесса разбирается в главе 2 и главе 4. Эмбеддинг это длинный список чисел, в который модель превращает текст, подробности вы найдёте в главе 7. Большего знать заранее не потребуется.

В этой главе у пиццы ровно два признака: сыр и острота. Никаких других признаков мы не вводим. Вектор [8, 2] означает восемь единиц сыра и две единицы остроты.

Представьте каталог из десяти тысяч статей. Пользователь открыл одну из них и хочет увидеть похожие материалы. Простое решение, плохо сравнивать тексты по совпадению слов. Этот подход работает poorly. Две статьи про автомобиль и про машину могут не содержать общих слов, хотя описывают одно и то же. Статьи про ягуара-животное и про ягуар-автомобиль могут иметь много совпадающих слов, хотя их смысл абсолютно разный.

В этой главе мы разберём, как измерять похожесть объектов по их смыслу, вместо сравнения по внешним признакам. Для наглядности мы будем использовать простой пример: описание пиццы двумя числами. У каждой пиццы есть ровно два признака: количество сыра и уровень остроты. Вектор это набор чисел, который описывает объект. Вектор [8, 2] означает, что в пицце восемь единиц сыра и две единицы остроты. Каждую статью мы тоже опишем набором чисел, где каждое число отвечает за отдельный смысловой признак.

Затем мы придумаем формулу, которая по двум наборам чисел выдаёт одно число: насколько два объекта похожи. Чем это число ближе к единице, тем выше похожесть. Такой подход лежит в основе поиска по смыслу, системы, которая находит материалы по смыслу запроса, а не только по совпадению отдельных слов.

Шаг 1. Описываем вещь числами

Чтобы сравнивать любые объекты, их сначала нужно описать набором чисел в фиксированном порядке. В математике такой упорядоченный набор чисел называется вектором. В этом разделе мы будем использовать пиццы в качестве примера: у каждой пиццы ровно два признака, по которым мы будем их описывать: количество сыра и уровень остроты. Оба признака измеряются по шкале от 0 до 10, а порядок чисел в описании зафиксирован заранее: сначала идёт значение для сыра, потом для остроты.

Пицца «четыре сыра» имеет вектор [8, 2], пицца «сырная с перчиком», вектор [7, 3], пицца «дьябло», вектор [1, 9]. Вектор [8, 2] означает, что у этой пиццы 8 единиц сыра и 2 единицы остроты. В этом примере у пиццы есть ровно две характеристики, и мы работаем с ними.

Сразу видно, что первые две пиццы очень похожи, дьябло стоит особняком. Цель этой главы, получить такой же вывод не по интуиции, а по точной формуле, которая посчитает степень похожести одним числом. Позже это умение пригодится и для сравнения пицц, и для поиска по смыслу, когда мы будем сравнивать тексты, изображения или другие сложные объекты.

Вектор это упорядоченный список чисел, в котором порядок элементов зафиксирован договорённостью и не меняется от объекта к объекту в одном каталоге. В этой главе мы описываем пиццу двумя числами: первое в списке всегда означает количество сыра, второе, уровень остроты. Например, вектор [8, 2] соответствует пицце с восемью единицами сыра и двумя единицами остроты. Если поменять числа местами, получится вектор [2, 8], он описывает уже другую пиццу: с двумя единицами сыра и восемью единицами остроты. Поэтому в определении используется слово «упорядоченный»: без фиксированного порядка одинаковые числа дают разные описания, и все расчёты в каталоге будут неверными.

Количество чисел в векторе называют его размерностью. У пиццы в нашем примере размерность равна двум, потому что мы используем ровно два признака для описания, и других признаков в этой задаче нет. В задачах обработки текста такие описания объектов называют эмбеддингами: это тоже векторы, только их размерность обычно составляет 768 или 1536 чисел. Принцип остаётся тем же: каждый элемент занимает строго определённое место, а весь список кодирует свойства объекта. Для пиццы мы кодируем вкусовые характеристики, для эмбеддинга кодируем смысл текста, но математически это одинаковые структуры, и с ними работают одни и те же формулы.

Шаг 2. Три действия над векторами

Сложение векторов выполняется по позициям признаков. Посмотрите на пример с пиццей: если первая пицца имеет вектор [8, 2], это восемь единиц сыра и две единицы остроты, а вторая, [1, 3], одна единица сыра и три единицы остроты. При сложении получаем [9, 5]: девять единиц сыра и пять единиц остроты. Складывать векторы разной длины нельзя. Если один объект описан тремя признаками, а другой двумя, нет соответствия позиций, и сложить их не получится.

Умножение вектора на число, или скаляр, затрагивает каждую позицию отдельно. Например, 3, умноженное на [8, 2], даёт [24, 6]. Это растягивает стрелку вектора втрое по той же прямой. Если множитель отрицательный, скажем, -2, получаем [-16, -4]: стрелка разворачивается в противоположную сторону, но остаётся на прежней прямой. Такое масштабирование используют для регулировки влияния отдельного признака при сравнении объектов.

Длину вектора считают по теореме Пифагора: каждый элемент возводят в квадрат, складывают результаты, из суммы извлекают квадратный корень. Для вектора [8, 2] это √(8² + 2²) = √68 ≈ 8,25. Длина показывает, насколько длинный вектор независимо от направления. Это одно число, которое позволяет сравнивать векторы без учёта их направления.

Эти три действия позволяют измерить сходство двух пицц одним числом. Для пары пицц с векторами [8, 2] и [7, 3] считают разность векторов: [1, -1]. Длина этой разности примерно 1,41. Если у другой пары разность [2, 0], её длина равна 2. Первая пара более похожа, так как расстояние между её векторами меньше. Позже, когда вместо сыра и остроты в векторах появятся смысловые координаты текста или изображения, этот подход ляжет в основу поиска по смыслу.

Считаем руками · длина

Длина вектора показывает, насколько длинный вектор в пространстве его координат. Для вектора с двумя координатами, как у наших пицц, формула выглядит так: из каждого числа берётся квадрат, складываются все квадраты, из суммы извлекается корень. Возьмём вектор [3, 4]. Квадрат 3 равен 9, квадрат 4 равен 16, сумма 9 и 16 равна 25, корень из 25 равен 5. Длина этого вектора 5.

Теперь посчитаем длину вектора пиццы A: у него восемь единиц сыра и две единицы остроты, так что он записывается как [8, 2]. Квадрат 8 равен 64, квадрат 2 равен 4, сумма 64 и 4 равна 68, корень из 68 примерно 8.25. Это и есть длина вектора пиццы A.

Если координат больше двух, например вектор [1, 2, 2], логика расчёта не меняется, только под корнем больше слагаемых. Квадрат 1 равен 1, квадрат 2 равен 4, ещё одно 2 в квадрате даёт 4, сумма 1, 4 и 4 равна 9, корень из 9 равен 3. Для трёх и более чисел формула остаётся прежней, меняется только количество слагаемых.

Промежуточный итог

Напомним три базовых действия над векторами, которые мы уже разобрали на примере пиццы. Складывайте векторы по соответствующим позициям. Умножайте вектор на число, применяя умножение к каждой позиции отдельно. Длину вектора считайте как корень из суммы квадратов всех его координат. В нашей задаче у пиццы ровно два признака: сыр и острота. Вектор [8, 2] означает восемь единиц сыра и две единицы остроты.

Всё дальнейшее в этой главе опирается только на эти три действия. Более сложные операции над векторами здесь не пригодятся.

Шаг 3. Измеряем похожесть

Чтобы получить одно число, отражающее похожесть двух объектов, перемножайте их числовые представления по соответствующим координатам и сложите все полученные произведения. Результат называется скалярным произведением векторов, его записывают точкой между ними: если векторы обозначены a и b, запись выглядит как a·b.

В этой главе у каждой пиццы два признака: количество сыра и уровень остроты. Вектор [8, 2] означает, что в пицце восемь единиц сыра и две единицы остроты. Допустим, у нас есть вторая пицца с вектором [7, 3]. Их скалярное произведение равно 8·7 + 2·3 = 56 + 6 = 62.

Эта формула работает благодаря свойствам умножения. Слагаемое в сумме получается большим, только если оба сомножителя в нём большие, то есть оба вектора сильно выражены по одной и той же координате. Если один вектор силён по сыру, а второй по остроте, в каждом слагаемом один множитель будет маленьким, и итоговая сумма окажется небольшой. Чем больше итоговое число, тем выше общая похожесть по обоим признакам сразу.

Считаем руками · насколько похожи пиццы

Проверим формулу на трёх примерах. Вектор A = [8, 2] соответствует пицце с 8 единицами сыра и 2 единицами остроты. Вектор B = [7, 3], пицце с 7 единицами сыра и 3 единицами остроты. Вектор C = [1, 9], пицце с 1 единицей сыра и 9 единицами остроты. Скалярное произведение двух векторов считают поэлементно: умножают координаты с одинаковыми номерами, потом складывают результаты.

Считаем похожесть A и B. Умножаем первые координаты: 8 * 7 = 56. Умножаем вторые координаты: 2 * 3 = 6. Складываем результаты: 56 + 6 = 62.

Теперь считаем похожесть A и C. Умножаем первые координаты: 8 * 1 = 8. Умножаем вторые координаты: 2 * 9 = 18. Складываем результаты: 8 + 18 = 26.

Сравниваем итоги: 62 больше 26. Значит пицца A больше похожа на B, чем на C. Формула повторила вывод, сделанный на глаз: четыре сыра ближе к сырной с перчиком, чем к дьябло.

Число, которое мы получили при скалярном произведении двух векторов, имеет понятный геометрический смысл. Оно показывает, насколько два вектора сонаправлены. Если стрелки векторов смотрят примерно в одну сторону, число будет большим и положительным. Если векторы перпендикулярны, число ровно ноль. Если стрелки смотрят в противоположные стороны, число отрицательное. Вы можете проверить средний случай самостоятельно на векторах [1, 0] и [0, 1]. Их скалярное произведение равно 1*0 + 0*1 = 0, что совпадает с правилом для перпендикулярных векторов. В этой главе у каждой пиццы ровно два признака: сыр и острота. Например, вектор [8, 2] описывает пиццу с восемью единицами сыра и двумя единицами остроты. Если сравнить эту пиццу с вектором [2, 8], их скалярное произведение будет положительным, что говорит о похожести по балансу этих двух признаков. Именно это свойство позволяет в дальнейшем измерять сходство объектов по их векторным представлениям.

Шаг 4. Где эта формула ломается

Добавим четвёртую пиццу в набор. Это та же четыре сыра, но составители меню перешли на стобалльную шкалу, поэтому её вектор теперь равен [80, 20]. Пицца не изменила рецепт, изменилась только единица измерения: теперь восемьдесят единиц сыра и двадцать единиц остроты, а не восемь и две.

Сейчас проверим на ней ту же формулу сходства, которую мы использовали для первых трёх пицц. Признаки пиццы в этой главе ровно два: сыр и острота, других мы не рассматриваем. Вектор [8, 2] означает восемь единиц сыра и две единицы остроты.

Посчитаем евклидово расстояние между исходной four cheese с вектором [8, 2] и новой: корень из (80-8)² + (20-2)² даёт примерно 78,9. Теперь посчитаем расстояние между маргаритой с вектором [4, 6] и новой пиццей: оно получится примерно 77,3. По формуле новая four cheese оказалась ближе к маргарите, чем к себе же в старой шкале. Причина в том, что длина вектора новой пиццы равна примерно 82,4, а старой, примерно 8,2. Формула реагирует на общую длину вектора и игнорирует соотношение сыра и остроты. Для поиска по смыслу нам важно не общее количество признаков, а их пропорция, поэтому здесь евклидово расстояние даёт неверный ответ.

Грабли · длина вектора искажает ответ

Посчитаем шаг за шагом скалярное произведение векторов A и D. Вектор A имеет компоненты [8, 2]: это 8 единиц сыра и 2 единицы остроты. Компоненты вектора D равны 80 и 20. 8 умножить на 80 даёт 640, 2 умножить на 20 даёт 40, сумма этих значений равна 680.

Сопоставим этот результат с похожестью A и B, которая по формуле равна 62. Получается, что по скалярному произведению A в десять раз сильнее похожа на D, чем на B. Но D это буквально та же пицца, что и A, только с увеличенной порцией ингредиентов.

Причина искажения в том, что скалярное произведение растёт не только при совпадении направления векторов, но и при увеличении их длины. У D длина в десять раз больше, чем у A, и этот вклад полностью перевесил совпадение по двум признакам, которые мы используем в этой главе: сыр и острота. Других признаков пиццы мы пока не рассматриваем.

Перенесём проблему на реальные данные. Когда мы кодируем текст в вектор, каждый элемент соответствует количеству признака в документе. Длинный текст даёт вектор с большими числами, короткий с маленькими. Если оставить формулу скалярного произведения как есть, поиск начнёт считать длинные документы похожими на любой запрос: их произведения с любым вектором будут больше из-за больших значений элементов. В этой главе признаки пиццы ровно два: сыр и острота. Вектор [8, 2] соответствует пицце с восемью единицами сыра и двумя единицами остроты. Длинный документ про сыр получит вектор вида [12, 3], его скалярное произведение с любым другим вектором будет больше, чем у короткого документа про острую пиццу [2, 5], даже если второй по смыслу ближе к запросу. Формула без учёта длины вектора искажает результат, отдавая приоритет объёму текста вместо смыслового совпадения.

Шаг 5. Убираем длину из формулы

Длина вектора мешает нам сравнивать только пропорции признаков, поэтому мы делим скалярное произведение двух векторов на произведение их длин. Полученное значение называется косинусной близостью, оно всегда лежит в диапазоне от минус единицы до единицы. Если векторы направлены в одну сторону, близость равна единице, если в противоположную, минус единица, при перпендикулярных векторах значение равно нулю. В нашей задаче у пиццы ровно два признака: сыр и острота. Вектор [8, 2] означает, что в этой пицце восемь единиц сыра и две единицы остроты. Например, если мы сравним её с пиццей, у которой шесть единиц сыра и полторы единицы остроты, косинусная близость покажет, насколько похожи их пропорции признаков, независимо от того, больше ли сыра в первой пицце в абсолютном значении.

Считаем руками · косинусная близость

У нас есть четыре вектора пиццы, каждый описывается двумя признаками: количество сыра и уровень остроты. Вектор [8, 2] означает 8 единиц сыра и 2 единицы остроты. Чтобы понять, насколько пиццы похожи, нужно сначала убрать влияние их общего размера.

Длина вектора равна корню из суммы квадратов его координат. Для вектора A = [8, 2] это корень из 68, примерно 8.25. Длина вектора B = [7, 7] равна корню из 58, примерно 7.62. Длина вектора C равна корню из 82, примерно 9.06. Длина вектора D = [80, 20] с тем же соотношением сыра и остроты, что и A, но в 10 раз больше по каждому признаку, равна корню из 6800, примерно 82.46.

Косинусная близость двух векторов равна отношению скалярного произведения к произведению их длин. Для пары A и B скалярное произведение равно 62, произведение длин примерно 62.8. Делим 62 на 62.8, получаем примерно 0.99.

Для пары A и C скалярное произведение равно 26, произведение длин примерно 74.7. Делим 26 на 74.7, получаем примерно 0.35. Для пары A и D скалярное произведение равно 680, произведение длин примерно 680. Делим 680 на 680, получаем ровно 1.00.

Единица означает, что векторы лежат на одной прямой в одном направлении: у них одинаковое соотношение сыра и остроты, независимо от общего размера. Так что D действительно та же пицца по балансу признаков, что и A. 0.99 означает почти полное совпадение соотношения, пиццы очень похожи. 0.35 означает большой угол между векторами, у пицц почти нет общего сочетания сыра и остроты.

Деление на длины векторов убирает влияние масштаба. Если взять любую пиццу и умножить количество сыра и остроты в два раза, её вектор удлинится в два раза, но соотношение координат не изменится. Косинусная близость между такой увеличенной пиццей и любой другой не изменится, так как обе части дроби увеличатся пропорционально. Это свойство используется при поиске по смыслу: объекты представляют векторами, и косинусная близость показывает, насколько они похожи по содержанию, а не по объёму.

a · b = a₁b₁ + a₂b₂ + … + aₙbₙ = |a| · |b| · cos θЛевая часть формулы считает скалярное произведение через координаты признаков: для пиццы с вектором [8, 2] (8 единиц сыра, 2 единицы остроты) и другой пиццы это сумма произведений соответствующих признаков. Правая часть показывает геометрический смысл: произведение длин векторов на косинус угла между ними, где |a| и |b|, длины векторов, θ, угол между ними. Выразив отсюда косинус, получаем формулу косинусной близости cos θ = (a · b) / (|a| · |b|), отдельную метрику для этого никто не изобретал, она вышла следствием из уже написанного.

Вспомним: каждый вектор пиццы описывается двумя признаками: количество сыра и уровень остроты. Например, вектор [8, 2] означает 8 единиц сыра и 2 единицы остроты. Длину вектора считают как корень из суммы квадратов его координат. В знаменателе формулы косинусной близости стоит произведение длин двух векторов, поэтому при расчёте нужно извлекать корень и делить.

Чтобы убрать лишние операции, применяют нормализацию вектора. При ней каждую координату вектора делят на его собственную длину. После нормализации длина любого вектора равна единице.

Если оба вектора нормализованы, произведение их длин в знаменателе формулы косинусной близости равно единице. В этом случае косинусная близость совпадает со скалярным произведением координат: перемножаете соответствующие элементы и складываете результаты. Такой расчёт работает быстрее.

Нормализацию выполняют один раз при загрузке документа в векторную базу данных. При каждом поиске по смыслу достаточно посчитать только умножения и сложения. Для наших пицц сравнение любых двух вариантов по схожести сводится к простой арифметике с двумя цифрами в каждом векторе.

Шаг 7. Другая длина и когда она нужна

В предыдущем шаге мы считали длину вектора по формуле Пифагора: брали разность по каждой координате, возводили в квадрат, складывали, извлекали корень. Это одна из возможных мер длины вектора, её называют нормой L2 или евклидовой нормой. Существует и другая распространённая мера, норма L1. Она считается проще: равна сумме модулей разностей координат, без квадратов и корня.

Разницу между этими мерами легко увидеть на примере города с прямоугольной сеткой улиц, например Манхэттена. Допустим, нужно попасть из точки [0, 0] в точку [3, 4]. По прямой, если бы можно было пройти сквозь дома, путь составил бы 5 кварталов. Это значение нормы L2. Но по улицам, двигаясь только по горизонтали и вертикали, придётся пройти 3 квартала по одной оси и 4 по другой, итого 7 кварталов. Это значение нормы L1.

Эти же меры работают и для признаков пиццы. У пиццы ровно два признака: количество сыра и уровень остроты. Вектор [8, 2] означает, что в этой пицце 8 единиц сыра и 2 единицы остроты. При сравнении двух пицц норма L2 покажет, насколько они отличаются по совокупности обоих признаков. Норма L1 покажет отдельные различия по сыру и остроте и сложит их.

Выбор между нормой L1 и L2 зависит от задачи. Если признаки не связаны между собой, например количество сыра не влияет на уровень остроты, норма L1 даёт более точный результат в таких случаях: она не штрафует за большое различие по одному признаку, если по другому пиццы почти совпадают. Если признаки связаны, например увеличение сыра обычно сопровождается повышением остроты, лучше подходит норма L2. При поиске похожих объектов по смыслу, когда векторы получают из текстовых описаний, выбор нормы определяет, какие пары объектов система сочтёт наиболее похожими.

Инженеру нужны разные способы измерения расстояния между объектами, потому что в задачах по-разному оценивают крупное отклонение по одному признаку и сумму мелких по разным. В этой главе у пиццы ровно два признака: количество сыра и уровень остроты. Вектор [8, 2] означает восемь единиц сыра и две единицы остроты.

Норма L2, или евклидова норма, считается как корень из суммы квадратов разностей координат двух векторов. Для пиццы [8, 2] относительно базовой [4, 1] это значение составит примерно 4,12. Если сравнить [6, 1] с отклонением по сыру на 2 единицы и [4, 2] с отклонением по остроте на 1 единицу, то по L2 расстояния будут 2 и 1. Квадрат координаты делает крупное отклонение более заметным, чем несколько мелких.

Норма L1, или манхэттенская норма, считается как сумма модулей разностей координат. Для пары [8, 2] и [4, 1] её значение будет 5. Для пицц [6, 1] и [4, 2] расстояния по L1 составят 2 и 1. Каждая единица отклонения вносит одинаковый вклад, независимо от признака. Именно поэтому L1 спокойнее переносит выбросы: аномально большое значение по одному признаку не увеличивает итоговое расстояние непропорционально сильно.

Эти нормы вы встретите в главе 5, когда будете разбирать регуляризацию, и в главе 12, где по L2 считают расстояние между эмбеддингами. Дальнейшие детали норм вам пока не нужны.

Шаг 6. То же самое на настоящих данных

До этого мы измеряли похожесть пицц по двум признакам, которые придумали сами: количество сыра и уровень остроты. Вектор [8, 2] означал 8 единиц сыра и 2 единицы остроты, и этого было достаточно для сравнения вариантов между собой.

Для текста такой подход не работает. Понять, насколько два предложения похожи по смыслу, по двум-трем простым характеристикам нельзя. Вам понадобится несколько сотен признаков, подобрать их вручную не получится.

Модель, обученная на большом объёме текстов из интернета, книг и других источников, принимает текст на вход и возвращает список из 1536 чисел. Такой список называют эмбеддингом. Что означает каждое число из списка, человеку неизвестно, и знать это для решения большинства задач не требуется.

Главное свойство эмбеддинга: модель подбирает числа так, что векторы для текстов с близким смыслом смотрят примерно в одну сторону. Векторы для предложений «кошка спит на диване» и «кот отдыхает на диване» будут направлены почти одинаково. В главе 7 разберём, как устроены такие модели и почему они работают.

Аналогия

Представьте анкету из 1536 вопросов, которую модель заполняет для любого текста. Вопросы она придумала сама во время обучения и не объясняет их значения словами. Анкета одинакова для всех текстов, поэтому полученные наборы ответов можно сравнивать между собой. Признаки пиццы в этой главе ограничены двумя пунктами: количество сыра и уровень остроты. Вектор [8, 2] означает восемь единиц сыра и две единицы остроты.

Эта аналогия не совпадает с реальностью полностью. В обычной анкете каждый вопрос имеет смысл сам по себе, а у эмбеддинга смысл несёт весь набор чисел целиком. Отдельная координата вектора обычно не несёт отдельного значения.

Раньше у каждой пиццы был вектор из двух признаков: количество сыра и уровень остроты. Вектор [8, 2] означает восемь единиц сыра и две единицы остроты. Мы перемножали соответствующие элементы двух таких векторов, складывали результаты и делили на произведение их длин. Получалось число от -1 до 1, где 1 означало полное совпадение по этим признакам. Эта формула остаётся прежней при переходе к текстам.

Теперь у каждого текстового фрагмента есть эмбеддинг, вектор из 1536 чисел, кодирующий его смысл. Формула расчёта похожести остаётся прежней: перемножаем элементы векторов по позициям, складываем все значения, делим на произведение длин векторов. Получается одно число, которое показывает, насколько два фрагмента похожи по смыслу.

Чтобы найти все похожие документы в базе, считайте это значение для пользовательского запроса и каждого документа в коллекции. Для тысяч документов такой перебор работает без задержек, а для миллионов нужны специальные методы ускорения поиска, о которых речь в главе 12.

Грабли · косинус меряет направление

Косинусная близость 0.9 между двумя текстами означает только то, что модель расположила их эмбеддинги близко по направлению в пространстве признаков. В этом числе нет никакой доли совпавшего текста. Описание пиццы с восемью единицами сыра и двумя единицами остроты, то есть вектор [8, 2], и описание пиццы с двенадцатью единицами сыра и тремя единицами остроты получат высокое значение косинусной близости, даже если сами описания почти не совпадают по словам. Порог релевантности подбирают отдельно под каждую задачу и модель.

У разных моделей эмбеддингов шкала косинусной близости работает по-разному. У одной типичная близость случайной пары текстов около нуля, у другой около 0.7, потому что её векторы сгрудились в узком конусе в пространстве признаков. Переносить пороги, подобранные для одной модели, на другую нельзя, это приведёт к ошибкам при оценке релевантности.

Разбор и практика

Вывод: откуда берётся формула косинусной близости

В этой главе мы описываем каждую пиццу двумя признаками: количество сыра и уровень остроты. Вектор [8, 2] означает, что в пицце восемь единиц сыра и две единицы остроты. Для двух таких векторов a и b скалярное произведение в координатной записи считается как сумма попарных произведений соответствующих координат: a·b = a₁·b₁ + a₂·b₂ + … + aₙ·bₙ. Эта формула работает для любого числа признаков, не только двух.

То же самое значение можно записать в геометрической форме: a·b = |a|·|b|·cos θ, где |a| и |b| это длины векторов, а θ угол между ними. Чтобы доказать, что обе записи описывают одно и то же число, воспользуемся теоремой косинусов для треугольника со сторонами |a|, |b| и разностью векторов a - b: |a - b|² = |a|² + |b|² - 2·|a|·|b|·cos θ.

Раскроем левую часть этого равенства через координатное определение скалярного произведения: |a - b|² = (a - b)·(a - b) = |a|² - 2·(a·b) + |b|². Приравняем это выражение к результату теоремы косинусов, сократим одинаковые слагаемые |a|² и |b|² в обеих частях. Останется равенство -2·(a·b) = -2·|a|·|b|·cos θ. Разделим обе его части на минус два, получим a·b = |a|·|b|·cos θ. Обе записи скалярного произведения совпали.

Выразим из этой формулы косинус угла между векторами: cos θ = (a·b) / (|a|·|b|). Эту величину называют косинусной близостью. У неё три полезных свойства: значение всегда лежит в диапазоне от минус единицы до единицы; длины векторов стоят в знаменателе, поэтому общий масштаб признаков не влияет на результат; если векторы имеют единичную длину, знаменатель равен единице и косинусная близость совпадает со скалярным произведением. На этом свойстве основана работа векторных баз для поиска по смыслу: объекты кодируют в единичные векторы, а для оценки похожести достаточно посчитать скалярное произведение.

Подумайте, какой признак пиццы ведёт себя таким образом. Затем вспомните, что в этой главе мы переходим к поиску по смыслу: у настоящих эмбеддингов, то есть векторных представлений смыслов, отрицательные координаты, обычное явление. Они позволяют улавливать понятия, противоположные по смыслу.

python
import numpy as np

A = np.array([8.0, 2.0])    # четыре сыра
B = np.array([7.0, 3.0])    # сырная с перчиком
C = np.array([1.0, 9.0])    # дьябло
D = np.array([80.0, 20.0])  # та же четыре сыра, шкала до ста

print(A @ B, A @ C, A @ D)          # 62.0  26.0  680.0
print(np.linalg.norm(A))            # 8.246...

def cosine(u, v):
    return (u @ v) / (np.linalg.norm(u) * np.linalg.norm(v))

print(cosine(A, B))                 # 0.987
print(cosine(A, C))                 # 0.348
print(cosine(A, D))                 # 1.0 ровно

# нормализация: делим вектор на его длину
def unit(v):
    return v / np.linalg.norm(v)

print(unit(A) @ unit(B))            # то же 0.987, деления больше нет

Коротко

  1. Вектор, упорядоченный список чисел. Его длину называют размерностью, она может быть любой. Например, два элемента для описания характеристик пиццы или 1536 для текстового эмбеддинга
  2. Скалярное произведение двух векторов вычисляется как сумма произведений чисел на одинаковых позициях. Чем сильнее векторы совпадают по направлению, тем больше итоговое значение
  3. Знак скалярного произведения показывает взаимную ориентацию векторов: плюс означает совпадение направления, ноль, перпендикулярность, минус, противоположные направления
  4. Скалярное произведение растёт при совпадении направления векторов и увеличении их длины, поэтому в чистом виде его не используют для поиска похожих объектов
  5. Косинусную близость вычисляют как скалярное произведение, делённое на произведение длин векторов. Её значение лежит в диапазоне от -1 до 1 и не зависит от масштаба исходных векторов
  6. Если векторы заранее привести к единичной длине, косинусная близость и скалярное произведение дают одинаковый результат, и на этом принципе работает большинство векторных баз данных.

1. Чему равно скалярное произведение векторов [2, 5] и [4, 1]?

Правильный ответ 13, потому что скалярное произведение считается как сумма произведений соответствующих координат векторов: 2 умножить на 4 равно 8, 5 умножить на 1 равно 5, их сумма даёт 13. Вариант 8 неверен: это только первое произведение, без сложения со вторым. Вариант 20 получается при перемножении координат крест-накрест. Вариант [8, 5] неверен, так как скалярное произведение всегда возвращает одно число, а не вектор.

2. Если скалярное произведение двух векторов равно нулю, что это означает?

При нулевом скалярном произведении угол между векторами составляет 90 градусов, то есть они перпендикулярны и не имеют общего направления. В поиске по смыслу это читается как отсутствие связи между текстами. Остальные варианты неверны: одинаковые векторы дают максимальное положительное значение произведения, противоположные по направлению - отрицательное, а разная длина не приводит к нулевому результату.

3. Каталог сравнивает документы по скалярному произведению без деления на длины векторов. Какая ошибка возникнет в первую очередь?

Правильный ответ: длинные документы окажутся наверху выдачи по любому запросу. При скалярном произведении без деления на длины у длинных документов значения координат больше, поэтому произведение получается больше независимо от смысла, как в примере с пиццей D из главы. Остальные варианты неверны: путаница синонимов зависит от способа обучения векторов, а не от отсутствия деления; отрицательные значения возможны и при корректном расчёте; поиск не перестаёт работать, просто ранжирование оказывается неверным.

4. Если векторы заранее нормированы до единичной длины, что можно упростить в расчётах?

Правильный ответ верен, потому что после нормировки длины обоих векторов равны единице, поэтому знаменатель в формуле косинуса обращается в единицу, и остаётся только числитель, скалярное произведение координат. Вариант с обрывом суммы неверен: для скалярного произведения нужно перемножить все пары соответствующих координат и сложить результаты. Вариант с уменьшением объёма хранения неверен: нормализация не удаляет координаты, их количество остаётся прежним. Вариант про бесполезность нормализации неверен: именно она позволяет упростить вычисление косинуса.

5. Косинусная близость двух текстов равна 0.82. Что можно из этого заключить?

Косинусная близость 0.82 означает, что векторы двух текстов направлены почти одинаково, то есть они семантически близки. Это значение показывает косинусную близость, поэтому по нему нельзя ни определить долю совпавшего текста, ни оценить разницу длины текстов, ни считать тексты точно одинаковыми: у разных моделей шкала косинусной близости разная, поэтому порог релевантности подбирают под конкретную задачу и данные.

6. Вектор, описывающий пиццу, записан как [8, 2]: первое значение соответствует содержанию сыра. Что описывает вектор [2, 8]?

Вектор описывает признаки объекта в зафиксированном порядке: первая позиция соответствует сыру, вторая остроте. Вариант [2, 8] означает 2 единицы сыра и 8 единиц остроты, то есть другую пиццу. Вариант «та же пицца, порядок не важен» неверен: порядок значений определяет смысл. «Та же пицца в другой шкале» неверен: смена шкалы масштабирует все значения, а не меняет их местами. «Запись без смысла» неверна: запись соответствует договоренности о позициях признаков, поэтому имеет смысл.

7. Вам нужно попасть из точки [0, 0] в точку [3, 4] по городу с прямоугольной сеткой улиц, сквозь дома идти нельзя. Сколько кварталов придётся пройти?

По прямоугольной сетке улиц можно двигаться только вдоль осей, поэтому суммарное число кварталов равно сумме модулей координат: 3 + 4 = 7, это норма L1. Вариант 5 это норма L2, длина по прямой, которая недостижима при движении по улицам. 12 получается как произведение координат, а 25, как сумма их квадратов, оба варианта не соответствуют условию движения по сетке.
